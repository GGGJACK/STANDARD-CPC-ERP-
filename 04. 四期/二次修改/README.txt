## 快速開始（給下一位工程師）

1. 先讀 HTML 第 0、1、6 章，知道改了什麼與代碼在哪。
2. 要驗證請用隔離副本，不要對正式 3000 端口跑寫入測試：

       cd 系统代码
       copy data.db _verify.db
       set PORT=3101
       set DB_PATH=...\系统代码\_verify.db
       set CPC_UPLOAD_DIR=...\系统代码\_verify-uploads
       node server.mjs

   （另一個窗口）

       set CPC_TEST=1
       set TEST_BASE=http://127.0.0.1:3101
       set DB_PATH=...\系统代码\_verify.db
       node 二次修改\verify-operation-2.mjs

3. 改完程式若要上線：關掉 启动系统.bat 視窗，重新雙擊啟動，瀏覽器 Ctrl+F5。
   資料庫結構未變，不需要遷移或 seed。
