# 標準清潔滅蟲 ERP 復刻系統

香港標準清潔滅蟲公司業務系統的復刻實現。單進程 Node.js 應用，SQLite 單文件數據庫，服務端渲染，無構建步驟。

覆蓋業務：客戶、報價、採購單、送貨單、產品與庫存、服務計劃、排班打卡、合約、發票收據、會計與員工管理。

## 快速開始

### 1. 準備數據

系統首次啟動時會從「原始數據導出」目錄自動導入數據。你需要有這份導出數據：

- 從項目資產庫下載 `ERP-01_業務數據快照_導出.zip` 並解壓
- 得到 `02. 數據導出/json/` 目錄（40 個 JSON 實體文件）

如果只是想跑起來看看界面，可以跳過導入，見下方環境變量 `CPC_AUTO_IMPORT`。

### 2. 配置路徑

代碼中的默認路徑指向原作者本機的 `F:/03 Standard CPC DataBase/...`，**在新機器上必須覆蓋**。在 `04. 四期/系统代码/` 目錄下創建啟動腳本：

```bat
@echo off
cd /d "%~dp0"
set CPC_DATA_DIR=D:\path\to\02. 數據導出\json
set CPC_ATTACHMENT_DIR=D:\path\to\03. 附件
node server.mjs
pause
```

macOS / Linux：

```bash
cd "04. 四期/系统代码"
CPC_DATA_DIR="$HOME/data/02. 数据导出/json" \
CPC_ATTACHMENT_DIR="$HOME/data/03. 附件" \
node server.mjs
```

### 3. 啟動

```bash
node server.mjs
```

控制台會打印三個地址：

```
本機：              http://127.0.0.1:3000
同一 WiFi 的同事：   http://192.168.x.x:3000
資料庫：            .../data.db
```

第二行是關鍵——**同一局域網內的同事直接訪問這個地址就能用**，不需要部署到公網。

## 環境變量

| 變量 | 默認值 | 說明 |
|---|---|---|
| `PORT` | `3000` | 監聽端口 |
| `DB_PATH` | `./data.db` | SQLite 數據庫路徑 |
| `CPC_DATA_DIR` | `F:/03 Standard CPC DataBase/02. 數據導出/json` | 原始 JSON 導出目錄，用於首次導入 |
| `CPC_ATTACHMENT_DIR` | `F:/03 Standard CPC DataBase/03. 附件` | 單據附件目錄 |
| `CPC_UPLOAD_DIR` | `./uploads` | 系統內上傳文件的存放目錄 |
| `CPC_AUTO_IMPORT` | `1` | 設為 `0` 跳過首次自動導入 |

## 數據庫約定（重要）

`data.db` 是單文件 SQLite，**不進 Git**，每個人本地各有一份。

| 場景 | 做法 |
|---|---|
| 拿到代碼後第一次跑 | 自動從 `CPC_DATA_DIR` 導入，生成 `data.db` |
| 想重新生成一份乾淨的 | 刪掉 `data.db`，重啟 |
| 只想補某幾張表的原始數據 | `node seed.mjs Customer Quotation`（`INSERT OR IGNORE`，不覆蓋已有修改，執行前自動備份） |
| 多人聯調需要一致數據 | 一台機器跑服務，其他人訪問它的局域網地址，**不要各自跑各自的庫** |

> 為什麼不共享 `data.db`：多人各持一份、各自改數據，最後對不上時極難排查。要麼各用種子數據改代碼，要麼共用一個運行實例。

## 協作流程

```bash
git pull                      # 動手前先拉
git checkout -b feat/報價單導出   # 開分支，別直接在 main 上改
# …改代碼…
git add -A && git commit -m "feat: 報價單支持批量導出"
git push -u origin feat/報價單導出
# 在平台上開 Pull Request，至少一人 review 後合併
```

提交前自查：

- [ ] `data.db`、`*.db-wal`、`backup-*` 沒有被 `git add` 進去
- [ ] 改動 `schema.json` 時同步更新 `seed.mjs`
- [ ] 跑過 `node test.mjs`，以及 `04. 四期/測試設計_20261025/run-tests.mjs`（≥107/115，P0 全綠）
- [ ] 對照 `00. 倉庫管理/倉庫約定.md` §5 門檻清單
